# DW2 · Little Things

> **联合制作署名｜S.A. · DW2**

TauriTavern（TT）独立便利工具扩展。首个模块 **Float Dock**，通过拖动将第三方悬浮球收纳到 ✧ 总控球内。

## 使用

拖动可识别的悬浮球到 ✧ 附近，松手后收纳。点击 ✧ 查看已收纳的球，点击图标尝试触发原插件，点击小 × 恢复该悬浮球。

在 TT 扩展设置里的 **DW2 · Little Things** 下可取消勾选「显示悬浮收纳球」，关闭时会恢复已隐藏的原插件按钮。也可使用「恢复全部悬浮球」。

## 当前版本

**v0.2.5-beta.1**：统一联合署名、优化扩展设置排序，拖拽其他悬浮球时自动收起已展开的收纳托盘，避免遮挡。修正备用识别逻辑，保留已正常显示的图标外观。

## 兼容说明

实验版本。不同插件的悬浮球可能使用 iframe、Shadow DOM、特殊触摸层或不同定位方式，无法保证全部可收纳。请在 iOS / Android 实机验证。仅修改本扩展仓库，不修改其他 DW2 插件。
