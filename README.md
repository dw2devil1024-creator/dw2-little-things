# DW2 · Little Things

> **联合制作署名｜S.A. · DW2**

TauriTavern（TT）独立便利工具扩展。

## v0.6.6-beta.1 · 魔法棒楼层操作新增可关闭的自动隐藏

- 原 Little Things「🪐 楼层操作」面板增加**默认关闭**的「自动隐藏旧楼层」开关、预设「保留最近 50 层」以及「自定义保留层数」（10～5000，整数）选项。选项与开关保存在现有 `dw2-lt-v2` localStorage 中，换聊仍使用同一设置，但只对当前聊天独立执行，不跨聊天混用楼层编号。
- 自动模式在切换聊天、完成生成、收到新回复/删除楼层后按需检测。当消息数量超过保留层数时，调用 TT 原生 `/hide` 排除**较早且未隐藏**的楼层；不会修改页面可见性、删除消息、自动恢复历史隐藏楼层或覆盖既有手动隐藏。
- 默认保护第 0 楼开场白及正文包含 `<abstract>`、`✦ 大总结`、`大总结 第N`、`总结范围：` 等明确标记的总结楼层；**不是自动总结功能，无法识别所有自定义总结格式，启用前请先总结重要剧情**。
- 生成过程中暂停自动隐藏，检测 TT 执行实际隐藏成功后才继续；聊天切换时中断剩余批次，最多每轮处理 12 段；原生执行失败时自动关闭开关并提示，防止无休止重复处理。手动「隐藏／恢复」按钮保留；想手动恢复被自动隐藏的旧楼层应先关掉开关，否则之后可能再被自动隐藏。
- 与书架、Preset Console 和 Resource Library 不共享存储或修改这些插件。基础模拟覆盖保留 50/自定义、开关关闭、摘要保护、聊天切换、原生失败暂停、事件注册清理；iOS／Android 真实 TT 运行仍需验收。

## v0.6.5-beta.1 · 魔法棒内置「楼层操作」

- 在 TT 原生魔法棒菜单 `#extensionsMenu` 中新增独立的「🪐 楼层操作」入口，**不**往聊天输入框上方添加快捷回复 QR，不占用已有悬浮收纳框；原有收纳框显示/隐藏与背景调节菜单项不受影响。
- 点击后打开隔离样式的 CLEAR MIST 雾玻璃操作台：🌙隐藏楼层 / 💫恢复楼层，支持单条索引（如 `12`）或连续范围（如 `0-10`），输入从 0 开始。点击确认才调用 TT 自己的 `executeSlashCommandsWithOptions('/hide ...')` 或 `/unhide`，不直接修改聊天数组或预设。
- 防误操作：未进入聊天、空值、非法字符、倒序、大于当前聊天末条索引等情况均不执行；确认期间锁住重复提交和关闭按钮；无需变量、无需助手模式/全文总结 QR。
- **楼层隐藏只从 AI 提示词上下文排除这些消息，不在聊天视图里隐藏消息，更不会删除聊天正文**。原先导入的 QR 不会自动消失，需要用户在 TT 快捷回复管理中禁用或移除旧操作台。
- 脚本基础语法、13 种楼层范围输入、9 项原生菜单接入与释放逻辑检查已通过；未进行 iOS/Android 真实操作验证。

## 安装与迁移

在 TT 的「安装扩展」中使用：

https://github.com/dw2devil1024-creator/dw2-little-things

**从 🌙背景调节 Lite v2.13 酒馆助手脚本迁移时：请先禁用旧背景调节脚本，然后刷新 TT；再打开 Little Things 的书签，点击最上方滑杆图标。** 不要同时运行旧脚本与内置模块，以免两个脚本争抢 #bg1 / #bg2 的背景样式。建议先禁用旧脚本，确认内置版本正常后再删除它。

## 原有功能与兼容说明

- 拖动第三方悬浮球至 little 书签附近收纳，点击已收纳图标可触发原插件，点 × 恢复该悬浮球。
- 魔法棒菜单可隐藏／显示收纳框；隐藏后停止拖拽命中检测，不清空已收纳悬浮球。
- 「显示悬浮收纳球」和「恢复全部悬浮球」沿用原有行为。
- 不修改 Story Archive、Preset Console 以及 TT 原生存档和预设。
- 背景调节模块已进行静态代码检查；iOS/Android 真实设备仍需更新后验收。
