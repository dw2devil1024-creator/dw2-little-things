# DW2 · Little Things

> **联合制作署名｜S.A. · DW2**

TauriTavern（TT）独立便利工具扩展。

## v0.6.1-beta.1 · Little Things 小工具箱

- 悬浮球收纳：原有 little 书签、收纳栏、魔法棒隐藏／显示和收纳记录全部保留。
- 🌙 背景调节：收纳栏最上方新增滑杆图标，点击打开内置调节器，无需安装酒馆助手脚本。
- 亮度／清晰度：沿用实机验收通过的 🌙背景调节 Lite v2.13 效果，亮度由黑色遮罩调节，清晰度由独立 backdrop-filter 模糊层调节，不放大缩小背景。
- 原图／夜间／柔和三档预设，临时原图预览，面板日夜配色、每张背景独立记忆全部保留。
- 扩展设置新增「启用背景调节」和「打开背景调节」，**默认关闭**，首次打开自动启用；停用模块时移除遮罩并恢复原有背景滤镜。
- 使用原脚本同一组 localStorage 键（st_bg_lite_v212 和 st_bg_lite_v212_panel_theme），可继承以前设置。
- 后台只在启用背景模块后检查背景切换，关闭时停止；独立于收纳球显示／隐藏。

## 安装与迁移

在 TT 的「安装扩展」中使用：

https://github.com/dw2devil1024-creator/dw2-little-things

**从 🌙背景调节 Lite v2.13 酒馆助手脚本迁移时：请先禁用旧背景调节脚本，然后刷新 TT；再打开 Little Things 的书签，点击最上方滑杆图标。** 不要同时运行旧脚本与内置模块，以免两个脚本争抢 #bg1 / #bg2 的背景样式。建议先禁用旧脚本，确认内置版本正常后再删除它。

## 原有功能与兼容说明

- 拖动第三方悬浮球至 little 书签附近收纳，点击已收纳图标可触发原插件，点 × 恢复该悬浮球。
- 魔法棒菜单可隐藏／显示收纳框；隐藏后停止拖拽命中检测，不清空已收纳悬浮球。
- 「显示悬浮收纳球」和「恢复全部悬浮球」沿用原有行为。
- 不修改 Story Archive、Preset Console 以及 TT 原生存档和预设。
- 背景调节模块已进行静态代码检查；iOS/Android 真实设备仍需更新后验收。
